
# 01-intro-react-ts

Minimal starter for learning React + TypeScript with Vite.

## Overview

This project is a small learning repository that uses Vite and TypeScript to introduce React concepts and TypeScript basics. It contains example TypeScript files under the `src/bases` folder and a minimal app entry in `src/main.ts`.

## Prerequisites

- Node.js (v16+) and npm (or pnpm/yarn)

## Install

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```

## Project structure

- `index.html` — app HTML
- `package.json` — project scripts & dependencies
- `tsconfig.json` — TypeScript config
- `src/` — source files
	- `main.ts` — app entry
	- `style.css` — basic styles
	- `vite-env.d.ts` — Vite types
	- `bases/` — example TypeScript exercises (01-const-let, 02-template-string, 03-object-literal)

## Notes

- Use this repo as a learning sandbox. Feel free to add exercises or convert the starter into a full React app.
